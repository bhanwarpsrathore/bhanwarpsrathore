## What I do

Most of what I work on is music infrastructure, Laravel, and PHP.

I build [HUTS Media](https://hutsmedia.com) for a company based in the Netherlands: distribution, royalties, contracts, and analytics. The API is TypeScript and Express. The app is React. Royalty runs and catalog imports sit on PostgreSQL, ClickHouse, Supabase, and BullMQ.

Before that I was at [Ubuy](https://www.ubuy.co.in) in Jaipur, first as a Senior PHP Developer and then as Software Development Team Lead.

The public code here is smaller. A Laravel channel for Twilio WhatsApp, PHP clients for Dropbox, Deezer, Labelcamp, and Notilify, and a PDF processor.

## A little story

I opened this GitHub account in 2016.

From 2017 to 2023 I was at Ubuy in Jaipur, building PHP products and React interfaces, and later leading the development team.

In 2023 I joined HMG and started working from home in Jaipur for a company based in the Netherlands. That work is HUTS Media.

The packages in this account came out of the same kind of work: notifications, API clients, and PDF processing I needed on real projects.
